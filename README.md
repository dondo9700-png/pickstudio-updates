# 픽스튜디오 업데이트
Windows용 픽스튜디오 배포 저장소입니다.
## 설치
[최신 배포](https://github.com/dondo9700-png/pickstudio-updates/releases/latest)에서 사용자용 ZIP 또는 업데이트 파일을 받으세요. 프로그램 사용에는 별도로 발급받은 사용권이 필요합니다.
## 자동 업데이트
2.3 이상은 새 버전을 확인하고 공식 서명을 검증한 패치를 다운로드합니다. 게시 도중에는 적용하지 않으며, 프로그램 종료 후 적용하고 다음 실행부터 새 버전을 사용합니다. 기존 문구, 연결 설정, 사용권과 기록을 유지합니다.
2.2 이하는 자동 업데이트를 시작하려면 최초 한 번 2.3 업데이트 파일을 실행하세요.
